# Cobertura dos roteiros

Todos os 43 metais elegíveis participam do roteiro eletrônico coletivo. Roteiros cristalográficos e de deformação ficam restritos aos metais com estrutura de referência suportada. Metais sem essa mecânica não recebem um cristal inventado. Elementos inelegíveis continuam identificados na tabela periódica, sem iniciar investigações.
