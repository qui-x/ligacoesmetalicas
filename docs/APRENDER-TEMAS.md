# Aprender — Temas

Os sete hubs são Ligação Metálica; Estrutura dos Metais; Estruturas Cristalinas; Elétrons Deslocalizados; Propriedades Metálicas; Medindo Estruturas; Da Estrutura ao Cálculo. Todos ficam disponíveis desde o início.

Cada tema reúne Ideia principal, Observe no SILM, Como interpretar e Limites do modelo, além de vínculos para o laboratório, missões, roteiros e fontes. O marcador Concluído é individual, explícito e reversível. Não existe sequência de desbloqueio nem percentual global.

Temas explicam conceitos; o Manual explica a operação. Nenhum laboratório é criado dentro de Aprender. Metais, critérios e fórmulas continuam no domínio científico central.

Os quatro marcadores antigos learning.theme.* reconhecidos são associados aos IDs atuais. O conteúdo anterior era um conjunto de pontos de entrada; os hubs atuais oferecem conteúdo não linear real. Os registros científicos antigos não são alterados pela migração de leitura.
