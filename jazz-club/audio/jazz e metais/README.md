# Jazz e Metais

Coleção instrumental original do **SILM — Clube de Jazz**, com 30 músicas inspiradas no jazz de Nova Orleans e em propriedades dos metais.

Esta pasta contém as versões musicais selecionadas, incluindo as **reorquestrações v0.2 das faixas 01, 02 e 03**.

Cada faixa tem MP3, OGG, MIDI editável, marcadores de sincronização e notas. O catálogo contém nomes de arquivos, BPM e SHA-256 de cada mídia.

## Integração

- Os metadados de cada faixa estão em `catalogo.json`.
- Os JSON de cada música contêm marcações para animar banda e dançarinos no Babylon.js.
- O áudio só toca após interação do usuário, conforme as políticas dos navegadores.
- As associações entre música e fenômenos metálicos são interpretações artísticas; a física real depende do motor científico do SILM.
- Não incluir os 30 áudios no cache inicial da PWA: carregá-los sob demanda.

## Publicação

Os arquivos binários deste pacote precisam ser efetivamente copiados para o repositório GitHub. A existência do catálogo no GitHub não significa que os MP3/OGG/MIDI já estejam publicados.
